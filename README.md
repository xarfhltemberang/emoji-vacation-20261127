# One Emoji, One Dream Vacation — 🏝️

One emoji, one dream: a tiny island, one palm tree, white sand underfoot
and turquoise water in every direction. No schedule, no crowds, no inbox —
just warm sun, a slow breeze, and nowhere else to be. It is the place you
picture when someone says "dream vacation," and this one emoji is the whole
daydream.

> 🏝️

Character count: 1 (U+1F3DD, DESERT ISLAND — a single Unicode code point).

## How to run

```sh
python3 main.py
```

This writes the emoji to `/output/entry.txt` (or to `$OUTPUT_PATH` when set),
with no trailing newline.
