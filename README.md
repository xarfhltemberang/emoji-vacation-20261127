# One Emoji, One Dream Vacation — 🗻

One emoji, one dream: standing at dawn beneath Mount Fuji, snow on the
summit, the air cold and clear, Japan spread out below. It is not just any
holiday — it is the trip you have pictured for years, a single mountain that
says "go" louder than a whole brochure. The emoji is the postcard.

> 🗻

Character count: 1 (U+1F5FB, MOUNT FUJI — a single Unicode code point).

## How to run

```sh
python3 main.py
```

This writes the emoji to `/output/entry.txt` (or to `$OUTPUT_PATH` when set),
with no trailing newline.
